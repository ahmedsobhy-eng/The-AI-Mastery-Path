### 💻 Module 02: Programming Languages for Data Science
## Open Source vs Free Software
While often used interchangeably, they represent different philosophies:
- **Free Software (FSF):** Focused on the **ethical freedom** of the user. It's about "Free" as in "Free Speech," not "Free Beer."
- **Open Source (OSI):** Focused on the **development model**. It’s a practical approach to building better software through collaboration and transparency.
- **Key Takeaway:** Both are free to use and support collaboration, but Open Source is more business-oriented.
### 💻 Data Science Languages: Java & Scala
Beyond Python and R, these JVM-based languages rule the Big Data world.

- **Java:**
  - The foundation of **Hadoop**.
  - Tools: **Weka** (Data Mining) and **Deeplearning4j** (DL).
  - Best for large-scale enterprise applications.
- **Scala (Scalable Language):**
  - The native language of **Apache Spark**.
  - Combines Object-Oriented and Functional programming.
  - Highly optimized for parallel processing and complex data workflows.
  ##   Other Programming Languages for Data Science
Beyond Python and R, several languages power the modern data ecosystem:
- **Java:** The backbone of **Hadoop** and enterprise systems.
- **Scala:** Native language for **Apache Spark**; high performance on JVM.

### 🔑 SQL: Non-Procedural vs. Procedural
- **Procedural Languages (e.g., C, Python):** The programmer specifies **HOW** to get the data (step-by-step logic, loops, conditions).
- **Non-Procedural Languages (SQL):** The programmer specifies **WHAT** data is needed. The Database Management System (DBMS) decides the best execution path.
- **Key Advantage:** SQL is more efficient for data retrieval because it abstracts the complex underlying storage logic.
