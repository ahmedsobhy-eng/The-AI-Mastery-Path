### 🐍 Python Libraries & Data Licensing
#### 1. Core Libraries:
- **NumPy:** High-performance mathematical computing (Arrays & Matrices).
- **Pandas:** Advanced data structures (DataFrames) for cleaning and analysis.

#### ⚖️ Data Licensing (CDLA):
- **CDLA-Sharing:** Requires sharing modified data under the same license terms.
- **CDLA-Permissive:** Allows full usage and modification with NO obligations to share back.
- **Project:** A Linux Foundation project designed for collaborative data sharing.
