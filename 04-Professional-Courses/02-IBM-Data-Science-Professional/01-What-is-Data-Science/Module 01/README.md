# Module 01: What is Data Science?

## Overview
In this module, I explored the foundational definitions of Data Science and what makes a successful Data Scientist.

## Key Takeaways
- **Definition:** Data Science is the process of uncovering hidden patterns and insights from data to solve complex problems.
- **The Data Scientist's Role:** It's not just about math and code; it's about being curious, telling a story with data, and helping organizations make informed decisions.
- **Big Data & Mining:** Learned how massive datasets are structured and the importance of "mining" them for gold (insights).

## Goal
To build a solid conceptual foundation before diving into technical tools and programming.

Note: This module is focused on foundational concepts and theoretical frameworks. No code implementation was required.

Core Concepts Learned:
The 5 Vs of Big Data: Starting with Volume (The scale of data).

Data Types: Understanding the difference between Structured, Semi-structured (JSON), and Unstructured data.

The Ecosystem: Introduction to tools like Hadoop (Storage), Hive (Querying), and Spark (Processing)

What is HDFS?
It's the storage layer of Hadoop. Instead of storing a large file on one machine, HDFS splits it into blocks and distributes them across a cluster of computers (Nodes like Abbott, Basil, etc.).

Key Benefit: Data Redundancy. If one node fails, the data is safe because it's replicated across other nodes.
### 🔄 Data Transformation & Storing
- **Transformation:** Preparing data for analysis by reducing dimensions (PCA) or converting continuous variables into categories (e.g., Income Levels).
- **Storage:** Saving processed data into systems like HDFS or SQL for efficient retrieval by ML models.

### 🎯 Mining & Evaluation
- **Mining:** Applying algorithms to discover hidden patterns or make future predictions.
- **Evaluation:** Measuring results against the initial goals to ensure business value and accuracy.
